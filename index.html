01 / 給音樂一個起點

點選可用音；更換 Key 會將選音與現有旋律一起移調。

規則式生成，不需登入。每次生成後固定音符，播放不會偷偷改曲。

電腦鍵盤 → 鋼琴鍵盤

白鍵 A S D F G H J K L ;，黑鍵 W E T Y U O P。按住發聲、放開結束；可同時按多鍵。Z／X 降／升八度。文字輸入或選單取得焦點時不攔截。

按一下「啟用鍵盤」後即可彈奏；音色使用目前編輯軌道。

錄製會保留音長、休止與同時發聲。第一個音開始計時，最多錄到目前設定的小節長度。

哼唱／口技 → 指定聲部

單人清唱即可，不必知道音名。先設定大約速度；哼唱辨識音高、長短與停頓，口技辨識敲擊時間。錄音僅在本機處理，最長 45 秒。

伴奏可先錄一條單音樂句；這版不辨識同時唱出的多音和弦。口技鼓聲分類是粗略估計，可在編輯區修正。

尚未錄音。可先試用示範，了解辨識流程。

辨識結果會先顯示在這裡，不會直接覆蓋作品。

這版不自動猜速度：按目前 BPM 換算拍數；不勾節奏對齊時保留原始時間。滑音、氣音、雜音或連續同音可能需要修正。示範是合成測試聲音，不代表真人辨識準確率。

02 / 試聽與調整

版本 1
準備播放

音色試聽 · 獨奏／群奏／中國樂器

各種音色都有名稱標示；中國樂器目前是合成近似，並非真人取樣。每軌的 3／6 聲部合奏模擬是同音源疊加，不是真實群奏錄音。比較獨奏與群奏請選兩種小提琴。
循環變化 · 節奏工具 · 效果器
固定循環

變化使用同一份起始譜，不會越改越遠。凍結後可直接儲存專案或匯出 WAV；WAV 只輸出目前顯示的一版。

規則節奏（歐幾里得分布）

把指定數量的敲擊盡量均勻分布在每小節。套用會取代目前編輯軌道的音符；已鎖定的軌道需先解鎖。

目前編輯軌道的效果

效果調整會停止播放；再次播放即可聽見。延遲間隔跟隨 BPM，為附點八分音符。

旋律編輯

點空格新增，再點音符刪除；拖音符右端改長短（每格十六分音符）。點右端或右鍵可選取，再用音長按鈕精確設定。左側音名可整列升降，右鍵可修改單音。空白就是休止。下方文字欄可修改精確時間。電腦鍵盤演奏與錄製請使用上方鋼琴鍵盤區。

演奏法 · 弦樂撥弦與吉他和弦

弦樂：只改指定片段

適用小提琴獨奏／群奏及大提琴群奏。依音符開始拍選取，不會把短音直接冒充撥弦。

木吉他：和弦指板配置與掃弦

採用常見開放和弦或可移動橫按配置，最多六條弦；掃弦音符依序觸發。這版仍是單音取樣組合，沒有真實掃弦／滑指錄音。

先點選一個音符選取音符時改音長；未選取時設定新音長。

格式：C4@0/1 → C4，從第 0 拍開始，持續 1 拍。休止以音符之間的空白時間表示。

匯入其他音樂檔

選擇 MIDI（.mid／.midi）、未壓縮 MusicXML（.musicxml／.xml），或 MP3、WAV、OGG、M4A、AAC、FLAC、WebM 錄音。檔案只在本機讀取，不上傳伺服器。

尚未選檔

音訊限 45 秒／30 MB，依瀏覽器解碼能力讀取。適合單人哼唱或口技；混音歌曲不能還原完整多軌。樂譜限 5 MB；目前不讀取 .mxl 壓縮樂譜或各軟體專用工程檔。

讀取後先預覽，採用才會修改作品。

片段放在作品第 0 拍開始。對應的軌道會被取代並鎖定；最多四個聲部，多餘聲部可另選。這版每小節固定 4 拍。

本專案專用格式／AI 複製貼上
這區只使用 Loop Garden 專案格式。AI 回傳的完整 JSON 可直接貼在下方，不必另存檔案。也可選擇 .json 或內含相同 JSON 的 .txt，讀取後再套用。
將要求貼到你使用的 AI，再把完整 JSON 貼回此欄。按「檢查並套用」會取代完整作品；格式錯誤則不修改。其他軟體的 JSON 不是本專案格式。
